RISC-V implementation of Conway's Game of Life

Status: complete • Date: 2026-04-27 • Tags: RISC-V, algorithms, emergence

Conway's game of life is a sort of animated grid that follows rules similar to a simulated scarcity and competition environment. This program was written in RISC-V assembly for simulation within RARS.

  • Repo: /projects/risc-v-life/

Summary

I was first introduced to RISC-V and RARS by a class I took in university. For those who are not familiar, RISC-V is an assembly archetecture that can be simulated on conventional hardware with tools like RARS. Writing code for RISC and RARS was initially very difficult for me, as it was the first time I was really interacting with assembley, but with lots of practice I have come to enjoy it.

This specific project is meant to simulate Conway's Game of Life. It does this by interacting with the Bitmap Display feature of RARS. See the attached video for a little more context.

Context

An excuse to do some more programming in RISC-V! I think it is a really promising archetecture, and I want to show off how cool it is!
